- **Course Hide Feature** - Hide courses that do not require course assistants from the Manage Schedule page.  Courses can be hidden and unhidden by clicking View Course for a course inthe Manage Schedule page and then clicking "Hide this course from Scheduling" at the top of the page beneath the header.
  
  Once a course is hidden you will also see the option to show the course again in the same location.  On the Manage Scheduler page there is a toggle button at the top which will display hidden courses, this will allow you to show a course once it is hidden.
	- Courses can only be hidden if there are no published shifts associated with it.
	- If the same course is included in an import after it has been hidden it will continue to be hidden until it is manually unhidden again.


1. **Access the Application**
    
    Navigate to: https://event.phillycodefest.com and log in.
    
2. **Verify Permissions**
    
    - You must have the **event_admin** role to manage sponsors.
        
    - If you do not see the **Event Admin** navigation menu on the right, you do not have the required access.
        
    
3. **Open Sponsor Management**
    
    - In the right-hand navigation, click **“Sponsor Management.”**
        
    - This page displays the current list of sponsors. From here, you can:
        
        - Edit existing sponsors
            
        - Archive sponsors
            
        - Add new sponsors
            
        
    
4. **Add a New Sponsor**
    
    - Click **“Add Sponsor”** at the top of the page.
        
    - Complete all required fields in the form.
        
    
5. **Upload Sponsor Logo (Requirements)**
    
    - Use a **color logo** (preferred)
        
    - Recommended: **transparent background**
        
    - Accepted formats: **JPG or PNG**
        
    - Maximum file size: **2MB** (smaller is strongly recommended for performance)
        
    
    **Performance Note:**
    
    Large images will slow down the sponsor page load time.
    
    **Optional Optimization:**
    
    Use a compression tool such as https://compressor.io/ to reduce file size without quality loss.
    
6. **Create Sponsor**
    
    - Click **“Create Sponsor.”**
        
    - The sponsor will now appear on the sponsors page.
        
    
7. **Next Steps**
    
    - After creation, sponsor invitations can be generated for the new sponsor.

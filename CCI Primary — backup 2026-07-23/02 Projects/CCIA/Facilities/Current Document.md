School of Computer and Information Sciences (SCIS) – Shared Computing Resources 

This section describes shared computing resources at the School level. PIs should review the listed resources and include in their own “Facilities, Equipment & Other Resources” document only those that apply to their proposal. 

SCIS hosts a variety of compute environments to support all levels of research, education, and administration, including Proxmox Virtual Environment and VMWare architectures, backed by storage in CEPH. Cloud environments for larger and shared projects are also available, depending on security and access requirements. SCIS continues to invest in these virtual resources, while also exploring emerging environments to best support SCIS research and teaching. CPU cores, storage, and memory are added at every opportunity to these flexible, scalable environments. 

Proxmox Virtual Environment 

SCIS runs a virtualization cluster using Proxmox Virtual Environment (VE) that consists of 960 AMD Epyc CPU cores and 3.2 TB of RAM, and has access to the SCIS network storage. The cluster also contains 6 Tesla T4 GPUs, 6 A40 GPUs, and 2 Blackwell 6000 GPUs for temporary connection to research Virtual Machines (VMs). Space for adding resources for dedicated GPU access is also available. This cluster provides distributed compute resources, allowing for large-scale projects, more flexibility, improved resource use, and higher uptime than individual compute nodes. A VM with limited resources is provided for research proofs of concept free of charge. To support the compute needs outlined in this proposal, the PI has budgeted $XXX to purchase additional hardware to increase resources allocated to their VM. Once purchased, these VMs are dedicated, allowing access to the research team only. 

Software-Defined Network Storage (CEPH) 

SCIS runs a Ceph cluster with approaching 1PB of raw capacity - 750TB of HDD-backed storage and 170TB of SSD-backed storage. This cluster provides distributed storage, enabling larger scale projects, better performance, and higher uptime than individual storage systems. SCIS provides a small amount of Ceph storage for proofs of concept free of charge. To support larger datasets in this proposal, the PI has budgeted $XXX to purchase additional storage. SCIS IT supports different storage configurations to ensure data protections as needed. 

Resources for Teaching/Instructional Innovation 

Classrooms are outfitted with laser projectors, 4K displays, class capture hardware, and the Wolfvision Cynap. The Cynap controls the AV distribution throughout the room and can simultaneously display up to 4 streams. These streams include the local PC, a laptop connected directly to the podium, or up to 4 streaming devices. Windows, macOS, iOS and Android devices can all connect wirelessly to the presentation system, allowing collaboration and freedom to roam the classroom for better interactivity. Wireless networking and outlets are also available for students throughout the classrooms. Laptops are available for checkout from the CCI Commons desk. In person lectures are recorded with the Echo360 video platform. All course sections have Canvas shells integrated with the campus enrollment database and Kaltura Drexel Streams repository for video and audio management. 

SCIS is also hosting an instance of Apache VCL, which is a Virtual Computing Lab environment that mimics the physical computer labs in SCIS. This technology allows both online and face-to-face students to have the same experience when using computing facilities. 

A suite of compute tools within the Tux Environment are also available for instructional innovation. Tux is a SCIS Ubuntu Linux compute cluster with shared storage and Drexel account logins. All faculty, staff, and students have access to the system and a default limit of 4GB of storage on it. Additional storage can be requested as needed. Standard Tux nodes (tux1, tux2, tux3, tux4, and tux5) support command-line SSH access. Each node runs as a VM on the SCIS shared compute environment and has 64GB of RAM, 32 AMD Epyc CPU cores, and an SSD-backed boot disk assigned to it. Tux GPU nodes also support command-line SSH access and Jupyter logins through a web browser. Each node has 64GB of RAM, 8 AMD Epyc CPU cores, and a Tesla T4 GPU with CUDA installed. These nodes support investigations into GPU compute and AI/ML projects. For larger projects, faculty can request direct storage on Float and Double. Jupyterhub allows faculty and students to run Jupyter notebooks in their web browser, providing them with access to notes, code snippets, terminal windows, and other resources with a graphical interface. Jupyterhub is available on a dedicated Tux CPU node with 64GB of RAM and 32 AMD Epyc CPU cores. Jupyterhub logins are also supported on the Tux GPU nodes for GPU compute projects. Faculty also have access to the local Gitlab server for code change management. It has built in CI/CD and project management capabilities. Gitlab is accessible on the public Internet. A local Node.js and Python web application server is available for student web application projects.

University Research Computing Facility (URCF) 

The URCF provides high-performance scientific computing and secure data storage to the Drexel community and other universities in the Philadelphia area. The URCF data center houses the Picotte cluster, which comprises over 4,000 CPU cores, almost 20TB of RAM, 650TB of data storage, and 48 Nvidia GPUs with 1.5 TB of total GPU memory. Picotte was acquired through a combined $1.2 million investment funded by Drexel and an award from the NSF’s Major Research Instrumentation program. DISE Cluster 

Drexel's in-development "Data-Intensive Science and Engineering" (DISE) cluster is a heterogeneous high-performance computing environment with a focus on AI/ML workloads. The cluster includes 24 discrete GPUs (16x NVIDIA H200, 8x NVIDIA A100) with approximately 2.8 TiB of aggregate high-bandwidth memory and two NVIDIA Grace Hopper superchip nodes, which integrate CPU and GPU compute using a coherent memory fabric, enabling low-latency accelerator access. The system also includes over 1200 CPU threads with 3.8 TiB of aggregate memory for service hosting and data pre-processing. 

Data-intensive workflows are supported by a multi-tier storage and data movement infrastructure. A high-performance parallel filesystem connected via 400 Gbps InfiniBand provides up to 100 GB/s aggregate read bandwidth for “hot” data actively under computation. Approximately 3 PB of object storage, accessible over a 100 Gbps network, provides scale-out storage for datasets and results. Three dedicated transfer nodes support data ingress, egress, and movement between storage tiers. Briefly describe how this resource will be used in the proposed work (e.g., We will use this cluster in Aim 1 of the proposed work to perform X.). 

Materials Characterization Core (MCC) 

The MCC is a multi-user facility that provides technical expertise and instrumentation for research in variety of areas including nanoscience and engineering, polymer research, biomedical engineering, and chemistry and physics of solid materials. The MCC occupies a 3,500 square foot laboratory in the Bossone Research Enterprise Building on Drexel's main campus that houses several electron microscopes, X-ray diffractometers, an X-ray photoelectron spectrometer, and a suite of sample preparation tools. Briefly describe how this resource will be used in the proposed work (e.g., We will use MCC in Aim 1 of the proposed work to perform X.).

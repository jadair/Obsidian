### TASK 6 — Project ID: keep auto-increment but allow manual entry

**File:** `showcase/project/models.py` — `ProjectIdea`

The `number` field is already `CharField(max_length=50, null=True, blank=True)` and manually editable. The auto-increment behavior is not currently implemented — it is just a free-text field.

**Changes:**

1. Add a signal or override `save()` on `ProjectIdea` to auto-populate `number` if blank:

```python
def save(self, *args, **kwargs):
    if not self.number:
        super().save(*args, **kwargs)  # get PK first
        # Generate number based on competition year + sequential count
        count = ProjectIdea.objects.filter(competition=self.competition).count()
        self.number = f"{self.competition.year}-{count:03d}"
        super().save(update_fields=['number'])
    else:
        super().save(*args, **kwargs)
```

2. Add uniqueness validation in `_validate_idea_form_data` in `views/ideas.py`: if a manual number is provided, check it doesn't collide with another idea in the same competition:

```python
if data['number']:
    qs = ProjectIdea.objects.filter(number=data['number'], competition_id=data['competition_id'])
    if idea_pk:  # edit mode
        qs = qs.exclude(pk=idea_pk)
    if qs.exists():
        errors['number'] = ['This idea number is already in use for this competition.']
```

3. In `idea_form.html`, add a helper text to the number field: "Leave blank to auto-assign."
